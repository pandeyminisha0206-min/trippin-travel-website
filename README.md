# ✈️ Trippin — Travel & Tourism Website

Trippin is a modern, responsive travel and tourism website designed with a futuristic dark high-tech user interface.

## 🌍 Features

- Responsive navigation bar
- Mobile hamburger menu
- Hero travel banner
- Travel search functionality
- Popular destinations
- Travel packages
- Package details modal
- Booking interaction
- Featured travel offers
- Countdown timer
- Responsive image gallery
- Gallery lightbox
- Customer review carousel
- About Us section
- Animated travel statistics
- Contact form validation
- Success and error notifications
- Scroll reveal animations
- Scroll-to-top button
- Fully responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Font Awesome
- Unsplash Travel Images

## 🎨 Design

The website uses a futuristic dark theme with:

- Neon cyan accents
- Glassmorphism effects
- Smooth animations
- Hover effects
- Responsive layouts
- Modern travel photography
